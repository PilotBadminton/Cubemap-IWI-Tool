Replacing the shared libraries:
Close the application before replacing files. Qt DLLs, PySide6 extension modules
and Qt plugins are in _internal/PySide6/. Shiboken6 files are in
_internal/shiboken6/. Build modified libraries for Windows x64 with a compatible
compiler, Python ABI and Qt/PySide6 ABI, then replace the corresponding files,
including matching plugins and dependencies. The application loads these shared
libraries directly. Users may rebuild and run the application with modified
LGPL libraries, and may reverse engineer the combined application to debug
those modifications.
